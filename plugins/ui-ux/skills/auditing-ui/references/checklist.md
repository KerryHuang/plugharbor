# 介面審查清單（通用）

每條一個可勾項，括號裡是怎麼查。受眾專屬的加項見 plugin 根 `references/` 下的 `audience-<名稱>.md`。

## 文字

- [ ] 短標籤（按鈕、標題、名稱）一行放完，只有句子可以折（截圖＋量測）
- [ ] 按鈕文字說明結果，沒有單獨的「確定」「OK」（grep 按鈕文案）
- [ ] 多語言版本都實際看過，沒有被截斷或溢出

## 互動

- [ ] 每個動作都有可見回饋（點擊、送出、失敗）
- [ ] 長時間操作有進度或載入狀態
- [ ] 返回與關閉的位置、符號全專案一致（grep）
- [ ] 除了流程起點，每個畫面都有返回路
- [ ] 要做選擇的彈窗不能點遮罩關；看完就走的面板才可以
- [ ] 同類元件只用一個實作，沒有手刻第二份（grep 元件建構處）
- [ ] 開關看得出開或關，關掉／停用用同一套樣式
- [ ] 桌面／網頁可用鍵盤完成主要流程，焦點順序合理

## 狀態

- [ ] 每個畫面的載入中、空資料、錯誤、成功、停用狀態都有設計
- [ ] 錯誤訊息說清楚發生什麼與下一步，不責怪使用者

## 視覺與版面

- [ ] 目標尺寸全部跑過，最小尺寸截圖親眼看過：沒被切掉、沒重疊、沒非預期橫向捲動
- [ ] 一般文字對比 ≥ 4.5:1，各主題（含暗色）都量過
- [ ] 不只靠顏色傳達資訊
- [ ] 點擊區夠大；放不下就擴大點擊區、不改外觀
- [ ] 顏色、間距、字級用 token／變數，沒有元件內寫死
- [ ] 疊放元素不蓋字；裝飾避開文字
- [ ] 橫向捲動的列有捲動提示

## 失敗處理

- [ ] 儲存讀寫（localStorage、檔案、網路）都有 try/catch 或錯誤處理；失敗走統一提示（grep `setItem(`、`save`）
- [ ] 讀到非空但解析失敗的資料，先備份再回預設值
- [ ] 寫完立刻重新載入的流程（匯入、換主題）先確認寫入成功
- [ ] 音效、動畫等非必要功能失敗不會擋住流程
- [ ] 等待外部事件（權限、網路、裝置）有逾時和可以按的退路

## 素材

- [ ] 沒有別人的商標或受保護素材；新素材附授權檔
