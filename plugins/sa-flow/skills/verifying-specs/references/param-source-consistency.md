# 8.9 參數化來源一致性 — 掃描步驟

> 對應 SKILL.md Task 8.9（`--cross` 模式，B13）。CRITICAL／WARNING 判準已寫在 SKILL.md，本檔只放掃描與過濾方法。

做法（不逐操作，改逐「值」）：

1. 從 FRD／SAD／BFS／FFS 掃出出現**兩次以上**的數值與樣式——長度、位數、精度、
   上限、預設值、格式樣板（如 `YY-XXXXX`、`[0-9][0-9]-[0-9]{5}`）、閾值。
2. **先過濾出規範性語句**（VR／BR 判斷條件、TC 期望值、欄位規格長度／格式）。
   敘述性複述、實證統計（DB 實查筆數／比率）、TC 具體測資一律放行——
   實測某案「8 碼」出現 40 次，其中僅 2 次落在規範性語句。
3. 每個留下的值逐一問「**誰算的**」：字面常數／自設定檔推導／自 schema 欄寬／自既有規則沿用。
4. 依 SKILL.md 的判準表定等級（同值一處推導一處字面＝CRITICAL；值有落點但全篇字面＝CRITICAL；
   出自 schema 未標來源＝WARNING；業務常數各處一致＝通過；敘述性/實證/測資不列入）。

## 實例

某案：本 skill 跑五輪至零告警仍未攔下「衍生號基底寫死 8 碼 vs 取號自
設定檔推導」——因為兩處字面都是 8，任何逐字比對都會判一致。本節即為此新增。
