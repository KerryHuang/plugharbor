# 要一致的元件

同系列 app 共用的元件規範。每個元件在本 app 的哪個檔案，見專案的 `this-app.md`（沒有就自己 grep）。
以下數值是一組已驗證過的範例，沿用或換成自己的都可以，重點是同系列 app 一致。

## 要一致的元件

| 元件 | 做法 |
|---|---|
| 標題 | 深紫實心字（範例 `#2b1d4e`），不加任何 text-shadow |
| 開關關掉 | `opacity: 0.6` 加灰階 |
| 範例（PWA）🔄 更新 | 提供手動更新入口；按下後全畫面遮罩鎖住並用短句顯示進度，連不上網路要念出原因、幾秒後自動解除；更新不能清掉孩子的進度 |
| 短標籤 | 按鈕、標題、地名一行放完 |
| 新功能通知 | 大功能上線時加一筆公告，首頁通知老玩家；小修正不加 |
| 範例（PWA）📲 安裝 | 只在尚未安裝的 iOS/iPadOS 瀏覽器分頁顯示小膠囊；點了跳說明框，用一兩句短話念出「分享 → 加入主畫面」的步驟；300ms 後點任何地方關閉並停語音 |
| 主題 | ☰ 選單「🎨 主題」打開大卡片選擇畫面（含「自動」），打開時念「選一個主題」、點卡片有選取音效、剛打開 300ms 內點卡片不算。**選擇**（`auto` 或主題 id）和**實際主題**分開：存檔、網址存的是選擇，預設 `auto`，`auto` 依本地月份換（開機判斷一次）；自動卡寫「現在：X」、✅ 標在選擇上。網址 `?theme=<選擇>` 優先並寫回；跨 app 連結帶選擇，對方認不得的 id 當 `auto`；各主題標題用米白實心字（範例 `#fff3e0`）、不加 text-shadow |
| 存檔失敗提示 | 存檔寫不進去（無痕、空間滿）時，畫面上方置中一條黃色提示（範例 `#ffe082` 底、`#3b2a1a` 字、全圓角），文字「沒辦法存檔，關掉 App 後進度會不見」；一次開機只跳一次、不念、5 秒消失 |
| 念題排隊 | 正在念的念完，新句子只留最新一句排隊；引擎沒在念就直接念。要立刻停一律走封裝的 stop（先清排隊再 cancel），不直接呼叫 `speechSynthesis.cancel()`；🔊 重聽也排隊，不先停 |
| 防誤觸 | 一個共用 guard：畫面、步驟、彈窗新建後 300ms 內的點擊不算；換步驟重新起算；連結同時擋預設動作 |
| 返回／關閉 | 返回一律左上 `◀`，關閉一律右上 `✖`；點遮罩可以關的只有「看完就走」的面板（新功能、預覽、抽屜），要做選擇的彈窗不能點遮罩關 |
| 暫停框 | 「▶ 繼續」＋寫明去哪的返回鍵（例如回上一層）；暫停要同時停流程、動畫、語音；分出勝負後拿掉 ⏸ |
| 結算 | 念結果；輸了也鼓勵（不只播失敗音效）；一個問題只問一次；結算時收掉比賽中的 HUD |

## 常見的合理差異

同系列 app 不必完全相同的地方，先在這裡記下來，避免被當成不一致：

- 同一個功能的入口位置（例如「繼續上一局」放在流程第一步或一顆獨立按鈕）：各 app 依自己的流程決定。
- 首頁分區：各 app 的區數、區名、卡片內容和配色各自決定。
- 主題背景的實作：用繪圖引擎（會動）或 CSS 背景（裝飾停在固定位置）可以不同；全螢幕背景動畫在平板上很耗電，CSS 版建議靜態。
- 念題排隊：有跟讀、亮字照時間跑的 app，念之前先 stop，可以另外提供「忙碌中」查詢給其他流程等念完。

## 踩過的坑

- 注音字不要用 text-shadow 疊外框：注音筆畫很細，8 方向陰影一疊就糊了。標題最容易中。
- 白字直接壓在淺色背景（天空、雲）上看不見：要在最淺的背景上量對比。
- 固定寬的圓裡放好幾個字，會被擠成直排：用 `min-width`＋`padding`。
- 版面檢查腳本回「沒問題」不代表沒破版：一定要截圖親眼看。
