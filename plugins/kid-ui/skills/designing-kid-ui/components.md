# 要一致的元件

同系列 app 共用的元件規範。每個元件在本 app 的哪個檔案，見專案的 `this-app.md`（沒有就自己 grep）。
以下數值是一組已驗證過的範例，沿用或換成自己的都可以，重點是同系列 app 一致。

## 要一致的元件

| 元件 | 做法 |
|---|---|
| 標題 | 深紫實心字（範例 `#2b1d4e`），不加任何 text-shadow |
| 通關／密語畫面 | 純色天空底（範例 `#5ec8f2`）加 25% 暗層，不畫山丘、雲、草地 |
| 開關關掉 | `opacity: 0.6` 加灰階 |
| 首頁左上 | 換角色膠囊＋存款；英文時存款在頭像下面 |
| 首頁右上 | ☰ 選單抽屜：新功能、說明、搬家、🔄 更新 |
| 🔄 更新 | 按下就收起抽屜、全畫面遮罩鎖住，中間依序顯示「檢查網路…」「拿新版…」「好了，馬上打開新版」；先連一次伺服器，連不上就在遮罩上顯示並念「要連上網路才能更新」、拿掉 ⏳，3 秒後解除、不重新載入；連得上就把聲音設定改回預設、解除所有 service worker、刪掉全部 Cache Storage，再帶亂數參數重新載入（等於清網站快取，但 localStorage 的進度不動） |
| 開局流程 | 一步一個問題、大按鈕按了就往下、左上 ◀ 回上一步、每步念題目；角色用首頁選好的，不再選一次 |
| 短標籤 | 按鈕、標題、地名一行放完 |
| 新功能通知 | 大功能上線時加一筆公告，首頁通知老玩家；小修正不加 |
| 首頁分區 | 半透明圓角框（範例 `rgba(255,255,255,.4)`、其他主題 `.16`，圓角 24px）；卡片 4:3、白框 4px、圓角 24px，寬 `clamp(84px, min(19vw, 33vh), 240px)`（螢幕高 ≤500px）／`clamp(84px, min(19vw, 28vh), 240px)`；螢幕高 ≤500px 時首頁標題 28px；跨 app 的連結做成卡片放進區內，下方一排只剩開關 |
| 📲 安裝 | 只在 iPhone、iPad 的瀏覽器分頁顯示（`navigator.standalone` 或 `display-mode: standalone` 為真就藏；iPadOS 用 Macintosh UA＋`maxTouchPoints > 1` 認）：首頁標題右邊同一排一顆小膠囊「📲 安裝」。點了播選取音效、跳白色說明框：標題「加到主畫面」、「先點 ⬆️ 分享，再點「加入主畫面」」；念標題和步驟，300ms 後點任何地方關並停語音 |
| 主題 | ☰ 選單「🎨 主題」打開大卡片選擇畫面（含「自動」），打開時念「選一個主題」、點卡片有選取音效、剛打開 300ms 內點卡片不算。**選擇**（`auto` 或主題 id）和**實際主題**分開：存檔、網址存的是選擇，預設 `auto`，`auto` 依本地月份換（開機判斷一次）；自動卡寫「現在：X」、✅ 標在選擇上。網址 `?theme=<選擇>` 優先並寫回；跨 app 連結帶選擇，對方認不得的 id 當 `auto`；各主題標題用米白實心字（範例 `#fff3e0`）、不加 text-shadow |
| 首頁按鈕尺寸 | 換角色、存款、☰ 選單字級 `clamp(16px, min(5vh, 2.6vw), 40px)`；下排開關是白色半透明膠囊、沒有框，字級 `clamp(14px, min(4.2vh, 2.2vw), 32px)`，跟分區排成一欄（不固定在最底下）；卡片字級 `clamp(16px, 4.4vh, 40px)`；手機上也照這個尺寸，不另設 44px 下限 |
| 存檔失敗提示 | 存檔寫不進去（無痕、空間滿）時，畫面上方置中一條黃色提示（範例 `#ffe082` 底、`#3b2a1a` 字、全圓角），文字「沒辦法存檔，關掉 App 後進度會不見」；一次開機只跳一次、不念、5 秒消失 |
| 念題排隊 | 正在念的念完，新句子只留最新一句排隊；引擎沒在念就直接念。要立刻停一律走封裝的 stop（先清排隊再 cancel），不直接呼叫 `speechSynthesis.cancel()`；🔊 重聽也排隊，不先停 |
| 防誤觸 | 一個共用 guard：畫面、步驟、彈窗新建後 300ms 內的點擊不算；換步驟重新起算；連結同時擋預設動作 |
| 返回／關閉 | 返回一律左上 `◀`，關閉一律右上 `✖`；點遮罩可以關的只有「看完就走」的面板（新功能、預覽、抽屜），要做選擇的彈窗不能點遮罩關 |
| 暫停框 | 「▶ 繼續」＋寫明去哪的返回鍵（回地圖／🏠 回大廳）；暫停要同時停流程、動畫、語音；分出勝負後拿掉 ⏸ |
| 結算 | 念結果；輸了也鼓勵（不只播失敗音效）；一個問題只問一次；結算時收掉比賽中的 HUD |
| 英文共用字串 | `✨ What's New`、`Got it`、繼續上一局 `▶ Keep going`、暫停繼續 `▶ Continue` |
| 搬家匯入 | 先把這台的進度備份到 `.before-import`（不碰 `.bak`）；存不進去不重新載入並說原因；認得同系列其他 app 的碼 |
| 清除記錄 | ☰ 最下面、跟其他項隔開；「↩️ 復原清除」只在有備份時出現、放在清除上面。面板只能按 ✖ 關，不念；家長題 9×9 乘法（2–9），答錯清空換題，答對「清除」才能按，按下就鎖住防連按。先把前綴開頭的 key 備份到 `<前綴>before-clear` 再刪；已經有備份時，清除面板用紅字提醒這次會蓋掉它；備份存不進去就不清並說原因。復原寫到一半失敗時備份留著 |

## 常見的合理差異

同系列 app 不必完全相同的地方，先在這裡記下來，避免被當成不一致：

- 「繼續上一局」的位置：可以是開局第一步，也可以是大廳的一顆按鈕。
- 骰子等遊戲素材的顏色：各自保留。
- 首頁分區：各 app 的區數、區名、卡片內容和配色各自決定。
- 主題背景的實作：用繪圖引擎（會動）或 CSS 背景（裝飾停在固定位置）可以不同；全螢幕背景動畫在平板上很耗電，CSS 版建議靜態。
- 念題排隊：有跟讀、亮字照時間跑的 app，念之前先 stop，可以另外提供「忙碌中」查詢給其他流程等念完。

## 踩過的坑

- 注音字不要用 text-shadow 疊外框：注音筆畫很細，8 方向陰影一疊就糊了。標題最容易中。
- 白字直接壓在淺色背景（天空、雲）上看不見：要在最淺的背景上量對比。
- 固定寬的圓裡放好幾個字，會被擠成直排：用 `min-width`＋`padding`。
- 版面檢查腳本回「沒問題」不代表沒破版：一定要截圖親眼看。
