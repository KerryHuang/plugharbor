# 規格書完成報告範本

## 調整模式

```markdown
## 功能調整規格書完成報告

**後端規格書（CR-BFS）**：`docs/{模組}/{功能}/{功能}_功能調整後端規格書_{ticket}.md`
**前端規格書（CR-FFS）**：`docs/{模組}/{功能}/{功能}_功能調整前端規格書_{ticket}.md`

### 異動摘要

| 類型 | CR-BFS | CR-FFS |
|------|--------|--------|
| [+] 新增 | {N} 個端點 | {N} 個元件 |
| [~] 修改 | {N} 個端點 | {N} 個元件 |
| [-] 移除 | {N} 個端點 | {N} 個元件 |
| ⚠️ Breaking Change | {N} 個 | {N} 個 |

### 下一步建議

- 規格書已完成 → 規劃實作（複雜功能）或直接開始實作
```
