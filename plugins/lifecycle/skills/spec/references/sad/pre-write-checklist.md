# 疑問點總清查（Step 9，寫文件前必做）

在開始撰寫文件前，**逐一檢查**以下面向是否仍有未解決的疑問：

| 面向 | 檢查問題 |
|------|---------|
| 工作流 | 每個角色的操作步驟都清楚？狀態流轉完整？ |
| 資訊流 | 每個資料項的來源和目標都確認？ |
| 資料流 | 所有涉及的資料表都已識別？讀寫關係明確？ |
| 邊界 | B1–B10、M1–M4 每個維度都有結論（含明寫「不適用」）？非法狀態轉換已定義？ |
| 一致性 | 交易邊界已識別（哪些操作需原子）？級聯影響與外部失敗的處理已定義？ |
| 重用性 | 現有系統可重用的資源都已確認？ |
| 跨模組 | 對其他模組的影響都已評估？ |
| 實現策略 | 技術方向建議的理由充分？NFR 都有約束／現況／陷阱三欄，且未寫手段？ |

**若仍有任何疑問**：回到步驟 2-8 重新搜尋或詢問使用者，直到全部解決。
**全部解決後**：才進入步驟 10 撰寫文件。
