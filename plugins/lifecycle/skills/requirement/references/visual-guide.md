# Visual Guide — 視覺素材收集

## §1.5 視覺素材收集

詢問使用者是否有既有畫面截圖或設計稿：

- **有提供** → 記錄並儲存為 `assets/{功能名稱}_mockup.{副檔名}`，§4 直接嵌入作為**參考**
- **未提供** → **不繪製 ASCII 版面**。§4 依 `references/screen-spec-format.md`
  撰寫業務層畫面規格（區塊清單 + 業務層有話要說的欄位 + 操作表 + 預設排序）；
  **不列完整四類欄位群**——那是 FFS §2 的 owner

> 需要給 PO／客戶做視覺確認時，可用線框稿或可點原型（工具不拘），
> 並在 PM 票掛連結。原型不進 Dev 票、不當版面依據。
