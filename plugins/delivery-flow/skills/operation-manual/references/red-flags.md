# Red Flags

> 由 `operation-manual` SKILL.md 指向。**收工前逐條掃一次。**

- **自行決定用哪個環境**（S1 必問，選錯整輪探索白跑）
- 在 production 或環境判不準時仍繼續
- 建測試資料沒帶「操作手冊示範用」字樣，或沒先確認該功能能不能刪
- 沒讀範本規範就開始寫（體例會跑掉）
- 把 clean 截圖直接放進手冊（讀者要自己找位置）
- writer 寫出 inventory 裡沒有的行為（幻覺）
- S6 未過就產 PDF
- 把規格落差寫進手冊當註解，而不是交棒出去
- **gaps 一律開票**——先分類再決定去處，開錯票會佔用 Dev 的時間
- **S6 未過就 commit**——檔案在工作區只是草稿，commit 才是交付
- 把含個資的 clean 截圖（`sNN-*`）放進 `{docs-root}`
- **跑完沒問使用者要不要產交付檔**（S8 是最後一棒，不是選用）
- 換機器沒跑 `ensure-tools.sh` 就開始，探索到一半才發現缺工具
- 沒問格式就自動產，或把交付檔寫進版控目錄
- 每跑完一棒就停下來請示，把一條完整的鏈拆成八次往返
- 能平行的兩棒寫成串接（S2a/S2b、S4/S5），讓後一棒乾等
- S4 用單一 agent 序列拍完所有截圖，在一個分頁反覆切換狀態
- 照抄別支功能的分組表，沒有先分析這一支的截圖前置狀態
- 客戶環境的真實個資寫進 inventory 範例值，一路傳給後續每一棒
- **S1 只給路由清單，沒給分支清單**（路由是「有幾個頁面」，分支是「同一頁有幾種樣子」）
- **探索回報有分支留白**，下游會把留白讀成「不存在」
- **S4 回頭對著 PNG 目測座標**，而不是用 inventory 記好的 `rect` 或 live DOM
- **客戶環境能換假資料卻去遮罩**（版面被蓋掉，讀者看不出畫面原本長什麼樣）
- 換完假資料沒跑 `verify()` 就截圖，或導航後沒重跑 `apply()`（SPA 會還原成真值）
- 把設備名稱、單據編號、群組名這些**非個資**也換成假值，害手冊失真
- **走備案遮罩時用 CSS／HTML 疊再截圖**，而不是用 `annotate.py` 的 `mask` 直接改像素
- **`可標註元素` 少了 `於:`**（rect 記了位置沒記狀態）
- **S2a 收件只數銷帳三態就放行**，沒跑 `check-inventory-rects.py`（曾致 S4 拒產 5／21 張）
- **照 MCP 全工具表派工**，沒先讀 agent 定義的 `tools:`（`upload_file`、`emulate` 都曾因此派錯）
- run-log 那一列「S1→S6 通過」又寫「無紀錄」
- **收件沒對帳 caption**，讓 S6 去抓 S4 的合理改動
- **S4 派工沒帶上游的環境前提**（測試資料可建次數、不可重複的操作）
- 遮罩蓋掉紅框的主角，或同一批圖遮罩標準不一；假名跨圖不一致（讀者以為換了個人）
- 平行派工只分了輸出檔名，沒分**工作目錄**
- 派工沒給 `isolated_context`，或沒要求開頁後 `emulate 1680x1000x2`
- 中途加派的補證棒排在 S3 之後跑，而不是跟 S3 平行
- **S4 標籤只驗「不壓紅框」**，沒驗標籤底下是不是畫面文字；擁擠的圖讓 agent 自選位置反覆試錯
- 手冊圖用 `badge`＋`legend`，整批圖尺寸不一
- **簡報只看 md 就過 S6**，沒產 PDF 跑溢出檢查（說明框被擠出投影片只有 PDF 看得到）
- 簡報靠縮小截圖塞版面（小於 `h:380`，截圖上的標籤讀不到）
