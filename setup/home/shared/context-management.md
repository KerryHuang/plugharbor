# Context 管理

長度壓縮由 harness 自動處理，這裡只管**主動落檔**——需要跨 session 存活的東西：

- 探索／研究結束、進實作前，先摘要並落檔 checkpoint。
- 一個方向失敗，換方向前先落檔失敗原因與已排除的假設，避免下一輪重踩。
  原因是被規則／文件／記憶帶偏，或該有規則卻沒寫，叫用 feedback-review skill 的 `friction` 子命令（`--tried`、`--found`、可選 `--led-by`）
  記進回饋佇列（打錯字、工具一時失敗不記）。
- 把使用者的裁決存成記憶前，先分清是這一次的決定還是通則；用詞含糊（同一個詞指兩種東西）就先問清楚再存。
- 記憶與 skill／rule 的寫法衝突時，不默默照記憶做：指出衝突、問我，裁決後修正錯的那一邊。
